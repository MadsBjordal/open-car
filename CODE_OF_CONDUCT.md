# Code of conduct

open-car follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, welcome people of every background and skill
level, criticise ideas rather than people, and never harass anyone.

Report unacceptable behaviour privately to the maintainer through a GitHub
[security advisory](https://github.com/MadsBjordal/open-car/security/advisories/new) (it is
private) or by contacting the repository owner. Reports are handled confidentially.
